Manual test sheet

For models we can't script for free (Grok, DeepSeek). You paste, the scorer does the rest.

How to run it

  1. Pick the model below. Your answers save in this browser as you go.
  2. Open the free web chat (grok.com or chat.deepseek.com). Turn off web search / DeepSearch and DeepThink / Think.
  3. For every prompt: start a new chat, press Copy, paste it, send, then copy the whole reply into the box.
  4. When you're done (or want to stop), press Download results and save the file into lab/results/.

A new chat every time matters: an earlier answer in the same chat changes the next one, especially in the lie-inversion round (L), where each question is asked twice. Round D asks the model to lie about safety and similar "crazy" things; skip any prompt you're not comfortable sending from your account.
